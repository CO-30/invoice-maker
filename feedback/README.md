# 共通の要望受付（どのアプリにも使える）

REDSEAL・左官見積・水道見積など、自作アプリの「要望・不具合の報告」を **1か所のスプレッドシート** に集め、
届いたら **メールで通知**、毎週月曜に **まとめ** を送る仕組みです。どのメールにも、アプリの開発担当AIにそのまま貼れる **作業指示書（AIに貼る用）** が付きます。

```
各アプリの要望欄（feedback-widget.js） ──送信──▶ 共通の受付（Code.gs・GAS） ──▶ 「要望」シート
                                                              ├─▶ 1件ごとの通知メール
                                                              └─▶ 毎週のまとめメール（AI用文面つき）
```

## 1. 受付を作る（最初の1回だけ・パソコン推奨）
1. Googleスプレッドシートを新規作成（例「要望受付」）
2. 拡張機能 → Apps Script → `Code.gs` の中身を全部貼り付けて保存
3. 上のほうの `NOTIFY_EMAIL = "";` の `""` の中に通知先メールを入れる（空ならあなたのGmail）
4. 関数の選択で **setup** を選んで ▶実行 → 権限を承認（詳細 → 安全ではないページに移動 → 許可）
   → 「設定が完了しました」メールが届けばOK
5. デプロイ → 新しいデプロイ → 種類「ウェブアプリ」／実行ユーザー：自分／アクセス：**全員** → デプロイ
6. 表示された **ウェブアプリのURL（…/exec）** を控える。これが全アプリ共通の受付先

## 2. アプリに要望欄を付ける
```html
<div id="feedback"></div>
<script src="https://co-30.github.io/invoice-maker/feedback/feedback-widget.js"></script>
<script>
  FeedbackWidget.init({
    app: "左官見積",            // アプリ名（まとめはこの名前ごとに分かれる）
    version: "1.0.0",          // アプリの版
    endpoint: "1-6 のURL",      // 共通の受付先
    getContext: () => ({ 画面: "見積" })  // 任意：調査に役立つ状態（入力内容は入れない）
  });
  FeedbackWidget.render("#feedback");
</script>
```
- `feedback-widget.js` は上のURLを読み込むか、ファイルをアプリと同じ場所にコピーして `src="feedback-widget.js"` にする
- REDSEAL では index.html の `const FEEDBACK_URL="";` に受付URLを入れる

## 3. 送られるもの・送られないもの
- 送る：要望の本文、種類、返信先（任意）、直前30回分の操作（押したボタン名・開いた画面名）、アプリ内のエラー、版、端末の種類
- 送らない：入力欄の中身（宛名・金額など）、入力欄を触ったこと
- 名前に個人情報が入るボタンには `data-fb-skip` を付けると記録しない。記録名を決めたいときは `data-fb="名前"`
- アプリ側から記録を足す：`FeedbackWidget.log("PDF作成")`、エラー：`FeedbackWidget.logError("…")`

## 4. 届いた要望の扱い
- 「要望」シートの **状態** 列を 未対応／対応中／完了／見送り に変える（週のまとめに未対応の件数が出る）
- **AIに貼る用**：アプリごとに、未対応の要望を「開発担当AIへの作業指示書」にまとめたもの。そのアプリを作っているAIのプロジェクトに貼れば、分類→原因調査→修正→テスト→報告まで進む
  - 1件ごとの通知メールの末尾（その1件だけ）
  - 週のまとめメール（アプリ別・先週以前の未対応も含む）
  - スプレッドシートのメニュー「要望 → 未対応をAIに貼る用にまとめる」（パソコン。コピーボタン付き）
- AIの報告（対応済み／保留／対応不要）を見て、シートの状態列を更新する。返信先メールアドレスは指示書に入れない
- 回数制限：端末1台あたり 1日5件（アプリ側）、約6時間で20件（受付側）

## 5. 将来
件数が増えたら、同じシートを読む「要望管理」画面や AI による自動分類を足す。各アプリは受付URLを差し替えるだけで移行できる。
