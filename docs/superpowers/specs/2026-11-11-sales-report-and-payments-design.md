# v1.11.0 売上集計（前年同月比）・入金管理・見積受注率・入金確認文面 設計書

- 日付：2026-11-11
- ベース：GitHub main（v1.10.0、コミット 7109bd3）
- 承認：プロジェクト指示「細かいことは聞かず決定して最終段階まで進める」により、設計判断はこの文書で確定する

## 1. 目的
販売（友人への紹介→有料化）を見据え、人気の有料請求書アプリが共通して持ち、このアプリに無い機能のうち「個人事業主がスマホで毎日使い、効果がすぐ分かる」ものを入れる。要望の中心は **昨年の毎月の売上との比較**。

## 2. 調査結果（2026-11 時点）
| 機能 | 採用しているアプリ | 本アプリの現状 |
|---|---|---|
| 月別売上グラフ・取引先別ランキング | Misoca（レポート：月別請求額、取引先上位20社）、Invoice Simple（月・取引先・品目別の入金レポート） | なし |
| 前年比・前月比・目標達成率 | 売上管理の基本指標（board の売上見込、販売管理系の売上対比表） | なし |
| 入金ステータス・未入金/期限超過 | Misoca・board・Invoice Simple・Zoho Invoice・Tofu | なし |
| 入金催促（リマインド） | Zoho Invoice（自動リマインド最大3回）、Invoice Simple（取引先明細書） | なし（送付文面テンプレートはある） |
| 見積の受注/失注・受注率 | Invoice Simple（sent/accepted/rejected/invoiced）、board（案件・受注管理） | 案件番号で見積→請求の紐付けはある |
| 取引先の再利用 | ほぼ全アプリ | 宛名の候補表示あり |
| 定期請求・オンライン決済・顧客ポータル | Zoho Invoice、board 等 | なし（サーバー・決済契約が必要なため今回は対象外） |

## 3. 採用する機能（YAGNI で絞った結果）
1. **集計タブ（📊 集計）** — 月別売上を今年と前年で並べた棒グラフ＋表（前年同月比）、年合計・前年比、累計（今月まで）比較、年間目標の達成率、取引先別・品目別ランキング（上位10）、見積の受注率、未入金残高。税込／税抜の切替。年度開始月を設定可（個人事業主は1月、法人は決算月の翌月）。CSV書き出し。
2. **過去の売上の手入力** — アプリを使う前の月（昨年など）の売上を月ごとに入力でき、前年比較に使える。Googleドライブの既存Excel取り込み・PDF取り込みで作った書類も自動で集計対象。
3. **入金管理** — 請求書に「入金済み／入金日」。一覧に「未入金」「期限超過」「入金済」の札と「未入金」絞り込み。
4. **入金確認の文面** — 未入金の請求書で LINE用／メール用の「お支払いのご確認」文面をテンプレートから作成（設定で編集可）。
5. **見積の状況** — 同じ案件の請求書・領収書があれば自動で「受注」、手動で「失注」にできる。一覧に札、集計に受注率。

見送り：一部入金、定期請求の自動発行、自動リマインド送信、オンライン決済（いずれもサーバー常駐・決済契約が必要）。

## 4. 売上の数え方（集計ルール）
- 売上＝**請求書**の請求日（date）で計上。見積は売上に含めない。
- 同じ案件（base）・同じ種別に改訂版が複数ある場合は **改訂番号（rev）が最大のもの1件だけ**（同点は updatedAt が新しい方）。案件番号なしの書類はそれぞれ独立。
- **領収書**は、同じ案件に請求書が無いとき（その場で現金受領など）だけ売上に数える。請求書があれば二重計上しない。
- 削除フラグ（deleted）の書類は除外。
- 金額は calc()（税込入力・端数設定を反映）の total（税込）または sub（税抜）。
- 手入力の過去売上は **税込額** で保存。税抜表示では 税込÷(1＋既定税率) の切り捨て。同じ月にアプリの書類があれば合算（アプリ外の売上として扱う）。
- 年度：開始月 fyStart（1〜12、既定1）。2026年度＝2026年 fyStart 月〜12か月。
- 前年比＝今年÷前年（前年が0なら表示なし）。累計比較は、表示年度が進行中なら今月までの同じ月数で比べる。
- ランキング：取引先別＝売上対象書類の合計、品目別＝売上対象書類の明細（摘要ごとの 数量×単価 の合計、明細金額そのまま）。
- 受注率：表示年度の見積（各案件の最新版）のうち、受注件数÷見積件数。
- 未入金：売上対象の請求書のうち入金済みでないもの（年度に関係なく全期間）。期限（due）が今日より前なら期限超過。

## 5. データ（すべて既存の書類JSON・設定に追加。シートの列は増やさない）
- 書類：`paid`（true/未設定）、`paidAt`（YYYY-MM-DD）、`lost`（見積のみ true/未設定）
- 設定：`fyStart`（"1"〜"12"）、`salesGoal`（年間目標・税込・空可）、`salesManual`（{"YYYY-MM": 税込額}）、`lineRem`／`mailRem`（入金確認の文面）
- GAS：書類は json 列に丸ごと入るため変更不要。設定は putSettings で同期される。
- 変換・改訂・複製で paid/paidAt/lost を **引き継がない**（新しい書類は未入金・検討中から）。

## 6. 画面
- 下部タブに「📊 集計」を追加（作成／一覧／集計／使い方／設定）。
- 集計画面：年度の ◀ ▶、税込/税抜、KPI（売上・前年比・累計比較・目標達成率・未入金・受注率）、SVG棒グラフ（今年＝濃色、前年＝淡色、色だけに頼らず凡例と表を併記）、月別表、ランキング、「過去の売上を手入力」、「集計をCSVで書き出し」、未入金一覧（タップで開く）。
- 編集画面（請求書のみ）：「入金済み」チェック＋入金日。未入金なら「入金確認（LINE）」「入金確認（メール）」ボタン。
- 編集画面（見積のみ）：状況表示（受注／検討中／失注）と「失注にする」チェック。
- 一覧：札（未入金・期限超過・入金済・受注・失注）と絞り込み「未入金」。
- 設定：年度開始月・年間目標、入金確認の文面2種。
- CSV（会計用）：末尾に「入金日」「状況」列を追加（既存列の順番は変えない）。
